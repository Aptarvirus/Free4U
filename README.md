# Free4U
A simple PDF Downloader

🚀 Features
      Direct URL Downloads: 
      Fetch and save PDF files by simply pasting the link. 
      Real-time Status Updates: Provides instant feedback during the download process . 
      Error Handling: Includes built-in alerts for invalid URLs or server-side CORS restrictions. 
      Responsive Design: A centered, user-friendly layout with a modern color palette.
  
Tech Stack
  HTML5
  CSS3
  JavaScript
  
For the structure of the downloader.  
  CSS3: Custom styling using a flexbox layout and rounded containers.  
  JavaScript (ES6+): Handles the asynchronous fetch requests and Blob object creation for downloads. 

📂 Project StructureThe project consists of three core files:pdf.html: 
  The main entry point containing the interface elements.       
  PDF.CSS: The stylesheet that handles the look, feel, and button hover effects. 
pdf.js: The logic that processes the URL and triggers the browser's download action.  

📝 How to UseOpen pdf.html in any modern web browser.     
  Enter the direct link to a PDF file in the input field. 
  Click the Download PDF button. 
  The file will be processed and automatically saved to your device as file.pdf.
